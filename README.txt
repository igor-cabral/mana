Cardápio digital — Maná Gastronomia
==============================

Esta pasta é um site estático pronto para publicar.

GitHub Pages:
  1. Coloque estes arquivos na raiz do repositório (index.html fica na raiz)
  2. git add . && git commit -m "Atualiza cardápio" && git push
  3. Settings > Pages > Deploy from a branch > main / (root)

Também funciona em Netlify, Vercel e Cloudflare Pages (arraste a pasta).

Para editar depois: no Gerador de Cardápios conecte a pasta (ou use "Importar" no ZIP).
O arquivo cardapio.json guarda todos os dados do projeto — não apague.
